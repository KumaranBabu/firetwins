11 · The work panels

Besides the Project Explorer and the 3D view, the main window has docked panels for the things you do most: change a value, read the check results, follow a run, show or hide layers, see the FDS input, and open results. Each panel can be closed, dragged to another side, or floated; Window > Show Panels brings any of them back, and Window > Reset Window Layout restores the default. The arrangement is remembered the next time you start PyFDS. The screenshots below are the finished case loaded in the real window.

11a · Properties: edit the selected object in place

PanelProperties (right side) · select an object in the Project Explorer or click it in the 3D view

Select any object and its fields appear in the Properties panel. Type a new value and press Enter or Apply; only the fields you changed are written, and Edit > Undo takes the change back. Revert discards what you typed. The same fields are available in the Edit > Properties dialog, so use whichever is more convenient. The status bar at the bottom shows how many objects are selected and the model coordinates under the mouse pointer (x y z, in metres) while it is over the 3D view.

11b · Validation: the list of findings

PanelMessages > Validation · Validate Project (toolbar) or the Validate button in the panel

Validate Project fills the Validation tab of the bottom Messages panel instead of opening a pop-up. The summary says Passed or FAILED with the number of errors, warnings and notes, and each finding is one line with its severity, message, the object it concerns and a hint on how to fix it. Double-click a finding to select that object in the tree and the 3D view. Auto-Fix applies the fixes the checker can make by itself and shows the new result.

11c · Run Monitor: follow a run without leaving the window

PanelMessages > Run Monitor · opens by itself when a run starts (Run > Run Simulation)

The Run Monitor tab shows the progress bar, the heat release curve and the end of the solver log, as the run writes them. It also works for a run started elsewhere. When the run has finished, Open Results Viewer opens the results next to the model (section 11f). The status bar carries the same information in short form, for example Run: running 45%.

11d · Layers: show and hide kinds of objects

PanelLayers (a tab beside the Project Explorer) · same switches as View > Show

Tick or untick Meshes, Obstructions, Vents, Devices, Init regions, Profiles, Geometry, HVAC, Grid, Axes and Labels to show or hide each kind of object in the 3D view. Show all and Hide all set every box at once. The boxes follow the View menu, so both stay in step.

11e · Output: the FDS input and the log

PanelMessages > Output

The Output tab has two pages. Log lists what PyFDS reports while you work. FDS Input is a read-only preview of the FDS input file the project would be written as, so you can check the namelists before a run. Nothing is saved by looking at it; press Refresh after changing the model.

11f · Results: open the run in a tab next to the model

PanelMessages > Results · the Results tab beside Model above the 3D view

The Results tab of the Messages panel lists the Smokeview result sets (.smv) found in the folder of the last run, or next to the saved project. Double-click one, or press Open in Results Viewer. The 3D Results Viewer (section 10) then opens as a second tab, Results, beside the Model tab above the 3D view, so the model and its results are in one window; click Model to go back. The Results tab can be closed with its × and opened again at any time. All the viewer's controls (Navigation View, time bar, Play, plots, pictures) work the same inside the tab.

11g · Workspaces

MenuWindow > Workspaces > Model / Run / Results

Three presets arrange the panels for the task at hand. Model shows the Project Explorer, Layers, Properties and the AI Assistant over the 3D model. Run shows the Project Explorer and the Messages panel on the Run Monitor. Results shows the Messages panel on the Results tab. Your own arrangement can be saved under a name with Window > Workspace… and restored with Window > Layouts….
