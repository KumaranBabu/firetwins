PyFDS icon audit

Every menu entry and toolbar button of the model editor and the Results window, read from the running application (offscreen) on 2026-10-29. Icons are the real ones the app draws.

Status: fixes applied (2026-10-29)

433entries now (11 duplicate commands removed)
0share a picture with another entry in the same menu (was 186; the 3 mirrored view pairs Front/Back, Left/Right, Top/Bottom keep theirs)
0plain-dot fallbacks (was 9)
18setting options shown without an icon, by design

Applied: per-command icon table (gui/icon_commands.py, checked before the wording rules); corner badges for add, import, export, library and open; colour variants (undo@view) where a recolour says enough; 27 new glyphs; options of one setting without icons; the misfiring and doubled rules fixed; Draw Stairs, the second Preferences, Geometry Repair, Import Scenarios, Focus 3D View / Hide Panels and the Views-and-Tours copies removed; Draw Wall renamed "Draw Wall by Coordinates"; time bar buttons icon-only with tooltips. A test now fails if two entries of one menu show the same picture.

Corrections to the first version of this audit: the time-bar glyphs (tostart, stepback, stepfwd, toend) and the overlay menu glyph were already in use - the code sets them directly, outside the menus the inventory read; the problem was the text arrow drawn beside each one. "Hardware Graphics Settings" has no double space: the label is "Hardware && Graphics", shown as "Hardware & Graphics". Below: the findings as they were before the fixes.

What causes it

Icons are not set per command. icons.py picks one from the entry's wording with 208 regular expressions, first match wins. Broad rules (^import, export, ^run, device, preferences|…, show/hide|^show) give whole menus one picture. Rule order also misfires: "Outlines Mode" hits profile|line and gets the sensor-line icon, and "Edit Zones" hits species|zone. 6 rules are listed twice.

Recommended fixes

  1. Badges instead of one verb icon. Draw the object's own glyph with a small corner badge: + for Add/New, an arrow in for Import, an arrow out for Export, books for Library. "Import Materials" then reads as materials-in, not as the 6 other Import entries, and "Add Mesh" differs from "Edit Meshes" while still saying "mesh". This one change fixes most of the repeats.
  2. No icons on options of one setting (units, time display, theme, geometry set): the radio mark is the information, and identical icons on every option only add noise. Keep icons on tool modes (Draw tools, navigation tools, render modes).
  3. Fix the misfiring rules and use the glyphs that already exist but are never shown: burner shaded_outline realistic_outline tostart stepback stepfwd toend app_results warning
  4. Draw 27 new glyphs where nothing fits: book, ceiling, cloud_run, cluster, eye_off, flow, home, jobs, layer, layout_1, layout_4, layout_h, layout_v, liquid, person, perspective, record, replace, roof, slope, smv_nav, sprinkler, stairs, template, trigger, window, zone.
  5. Remove or rename duplicate commands: Draw Stair (form) and Draw Stairs (tool dialog) both draw stairs; the two Draw Wall entries need names that say how they differ; several Results entries sit both in View and in View > Views and Tours.
  6. Results time bar: each button showed its glyph and a text arrow (|<, <) beside it.
  7. Make icons explicit per command (a table keyed by command, with the wording rules kept only as the fallback), and add a test that no two entries in one menu share a glyph unless listed as a deliberate pair (Undo/Redo, Front/Back).

Findings by menu

Highlighted rows have a finding. Entries in the same menu with the same icon and no finding are deliberate pairs (e.g. Front/Back, Save/Load Bookmark) or the same object (Edit Meshes beside the Meshes filter).
